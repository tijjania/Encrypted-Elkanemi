# 🔐 Encrypted-Elkanemi

A Python-based encryption and decryption application built to demonstrate practical cryptography and cybersecurity concepts.

Encrypted-Elkanemi supports both **message encryption** and **file encryption** using Fernet symmetric authenticated encryption from the Python `cryptography` library.

## 🚀 Features

- 🔑 Secure encryption-key generation
- 🔐 Text/message encryption
- 🔓 Text/message decryption
- 📁 File encryption
- 📂 File decryption
- 🛡️ Local secret-key protection
- ⚠️ Error handling for missing files and invalid keys
- 💻 Simple command-line interface

## 🛠️ Technologies

- **Python 3**
- **Cryptography**
- **Fernet symmetric encryption**
- **Git**
- **GitHub**
